# NovelScript Engine v1.3 Desktop（Windowsネイティブ版）

ブラウザやWebViewを使わず、Windows標準のデスクトップウィンドウとして動作するGUIシナリオエディタ／テストプレイヤーです。

## 利用者のPCにPythonは不要

完成した NovelScriptEngine.exe はPythonランタイムとTk/Tclをアプリに同梱する単体実行ファイルです。利用者はPythonをインストールする必要がありません。通常利用時のインターネット接続も不要です。

## v1.3：画面クリックで文字送り

ゲーム画面の背景・立ち絵・本文欄など、選択肢カード以外の場所をクリックすると次の文章へ進みます。

- タイプライター表示中は、1回目のクリックで現在の文章を全文表示します。
- もう1回クリックすると次の文章へ進みます。
- 選択肢の待機中は背景クリックで勝手に進まず、画面内の選択肢カードだけが選択されます。
- 選択肢カードのクリックは分岐だけを実行し、次の文章を誤って飛ばしません。
- wait命令の待機中はクリックで時間待ちをスキップしません。

## 画面内選択肢（v1.2）

選択肢を背景・立ち絵・本文ウィンドウと同じゲーム画面内にカード状で表示します。マウスまたは数字キー1〜9で選択できます。選択肢の長さや数に合わせて表示領域を調整します。

## 文字表示のカスタマイズ（v1.1）

「文字表示設定」から、フォント、文字サイズ・太さ・色、文字揃え、会話ウィンドウ／全画面テキスト／字幕レイアウト、表示位置・高さ・余白・背景・枠線・透過、タイプライター表示と速度を設定できます。設定は次回起動時にも保存されます。

## Windows EXEの取得

GitHubの Actions → Build Windows EXE → Run workflow を実行します。完了後、Artifactsの NovelScriptEngine-Windows-x64 をダウンロードし、ZIPを展開して NovelScriptEngine.exe をダブルクリックします。ソースZIPを更新してmainへ登録した場合も自動ビルドされます。

ビルド時のみGitHubのWindows runner上でPython 3.12とPyInstallerを使います。利用者のWindows PCにPythonは不要です。

## 主な機能

- .nse / .txt シナリオの作成・編集・読み込み・保存
- .nproj の読み込みと .nse への変換
- シーン／ラベル一覧、ジャンプ、命令テンプレート、構文チェック
- ネイティブウィンドウのテストプレイヤー
- 背景・立ち絵・選択肢・分岐・変数・エンディング
- WAV形式のBGM／効果音
- 約5分のサンプルプロジェクトとオリジナル素材

素材の権利情報はソースZIP内の ASSET_CREDITS.md を参照してください。
