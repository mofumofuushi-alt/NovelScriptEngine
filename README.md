# NovelScript Engine v1.2 Desktop（Windowsネイティブ版）

ブラウザやWebViewを使わず、Windows標準のデスクトップウィンドウとして動作するGUIシナリオエディタ／テストプレイヤーです。

## 利用者のPCにPythonは不要

完成した NovelScriptEngine.exe はPythonランタイムとTk/Tclを同梱する単体実行ファイルです。利用者はPythonをインストールする必要がありません。通常利用時のインターネット接続も不要です。

## v1.2の変更：画面内選択肢

選択肢をゲーム画面の外側ではなく、背景・立ち絵・本文ウィンドウと同じゲーム画面内にカード状で表示します。カードはクリックで選べるほか、数字キー1〜9でも選択できます。選択肢の数や文章量に合わせて会話パネルを自動拡張し、表示設定（フォント・文字色・配置）も反映します。既存の select 命令、分岐先、命令順は維持しています。

## 文字表示のカスタマイズ

メイン画面の「文字表示設定」から、インストール済みフォント、文字サイズ・太字、本文と話者名の色、左／中央／右揃え、会話ウィンドウ／全画面テキスト／字幕レイアウト、表示位置・高さ・余白・背景・枠線・透過パターン、タイプライター表示と速度を設定できます。設定は次回起動時にも保存されます。

## Windows EXEの取得

1. GitHubの **Actions** タブを開き、**Build Windows EXE** を選びます。
2. **Run workflow** を実行します（ソースZIPを更新してpushした場合も自動で起動します）。
3. 完了した実行のArtifactsから **NovelScriptEngine-Windows-x64** をダウンロードします。
4. ZIPを展開し、NovelScriptEngine.exe をダブルクリックします。

利用者のWindows PCにPythonは不要です。ビルド時のみGitHubのWindows runner上でPython 3.12とPyInstallerを使います。

## その他の主な機能

- .nse / .txt シナリオの作成・編集・読み込み・保存
- .nproj の読み込みと .nse への変換
- シーン／ラベル一覧、ジャンプ、命令テンプレート、構文チェック
- ネイティブウィンドウのテストプレイヤー
- 背景・立ち絵・選択肢・分岐・変数・エンディング
- WAV形式のBGM／効果音、5分間のサンプルとオリジナル素材

素材の権利情報はソースZIP内の ASSET_CREDITS.md を参照してください。
